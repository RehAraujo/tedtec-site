# TED TEC Hero Preview

Controlador isolado do motion aprovado do Hero TED TEC. O nome do plugin foi mantido por compatibilidade, embora ele também atenda a Home pública.

- carrega assets somente nas páginas `509` e `1091`;
- mantém o mesmo comportamento entre produção e homologação;
- Não possui dependências externas.
- Exclui seu único arquivo JavaScript do atraso/combinação do LiteSpeed.
- Pode ser revertido imediatamente por desativação.

O conteúdo editorial e o CSS permanecem nas respectivas páginas do WordPress. Exports brutos não são versionados porque podem conter metadados temporários do editor.
